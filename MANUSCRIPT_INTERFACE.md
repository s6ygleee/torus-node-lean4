# Manuscript interface

This verification archive is prepared for the Physical Review D manuscript,
but it does not contain the manuscript source or PDF. The hashes below identify
the manuscript version that this release accompanies:

| Item | SHA-256 |
|---|---|
| Main manuscript PDF | `E81159B0F25C90FC258AA71A2F35EF819384B7F203451667DC0F4D0B5F77FCFD` |
| Verification supplement PDF | `83A6062A95A3C590C0877343DF18533AA49916602BF6DC8AD50E52F9CE6511E6` |

Each release of this archive records the hashes of the manuscript version it
accompanies.  Releases are additive; an earlier release is never rewritten.
