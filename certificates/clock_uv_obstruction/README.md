# UV obstruction to naive clock-field H7 compactness

For one pinned massless clock component on an (L^4) lattice,
equipartition gives
\[
\mathbb E\sum_{\ell}|\Delta T_\ell|^2
=\frac{L^4-1}{\kappa_t}.
\]
The continuum-scaled four-dimensional Dirichlet energy is
\[
E_{\rm cont}(L)=a^{4-2}\sum_\ell|\Delta T_\ell|^2,
\qquad a=L^{-1},
\]
so
\[
\mathbb E E_{\rm cont}(L)
=\frac{L^4-1}{\kappa_t L^2}
\sim \frac{L^2}{\kappa_t}\to\infty.
\]
The executable sweep confirms this quadratic divergence. Consequently the
massless clock measure is not tight in an (H^1)-type topology under the
naive continuum scaling. The earlier deterministic Rellich lemma remains
valid for bounded-energy sequences, but cannot be applied to this raw Gaussian
measure without a UV counterterm, a distributional topology, or a different
scale normalization.

This is a precise H7 boundary, not a failure of the finite model. A continuum
completion must choose one of: (i) renormalized clock action/field, (ii) a
negative-Sobolev distributional limit, or (iii) a massive/coarse clock with a
different scaling rule.
