# first support-six obstruction to the fixed-background expansion

A plaquette-admissible support-six witness was found and rechecked at 192-bit
Arb precision:

\[
 (\operatorname{Tr}X^{32})^{1/32}
 =1.0010951332891217\ldots>1.
\]

Hence the single (K_0)-centred Neumann expansion cannot uniformly cover all
support (6\)–(17) fields.  This is a no-go for that representation, not a
no-go for the electroweak measure: larger polymers require background
recentering or a genuinely connected cluster expansion.
