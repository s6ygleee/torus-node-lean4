# exact periodic (D_4) Hodge/coexact coercivity

For the deterministic periodic lattice \((\mathbb Z/L\mathbb Z)^4\), the
Fourier symbol of the discrete Hodge Laplacian on every nonzero momentum is
\[
\lambda(k)=4\sum_{\mu=1}^4\sin^2(k_\mu/2).
\]
On the coexact 1-form and 2-form subspaces the symbol is
\(\lambda(k)I\). Removing harmonic modes at \(k=0\), the exact minimum is
\[
\lambda_{\min}^{\rm coexact}(L)=4\sin^2(\pi/L),
\qquad
L^2\lambda_{\min}^{\rm coexact}(L)
\to4\pi^2.
\]

The executable sweep \(L=2,3,4,5,6,8,12,16,24,32,64\) reproduces this
formula exactly; for example
\[
L=4: \lambda_{\min}=2,
\quad
L=8: \lambda_{\min}=0.585786437627,
\quad
L=32: \lambda_{\min}=0.038429439193,
\]
and the rescaled values increase to \(4\pi^2=39.4784176044\).

Thus the periodic (D_4) consumer has an exact volume-scaled coexact
Poincare/coercivity bound. This strengthens the finite bounded-geometry gate.
It does not overcome the unrestricted Poisson isolated-vertex obstruction,
and it is not yet a source-native interacting continuum compactness theorem.
