# Continuum-boundary diagnostic index

This directory contains five compact, public-facing records for the estimates
that delimit the present source-to-continuum argument. The records use
descriptive mathematical names throughout.

1. `compact_rotor_coercivity.md` records the compact-rotor low-mode test and
   the exact quotient obstruction.
2. `componentwise_sector_bounds.md` records the separate coframe, clock and
   Higgs estimates.
3. `signed_feshbach_pole_residue.md` records the finite signed Feshbach ratios
   and pole-residue tail estimates.
4. `wilson_villain_cluster_boundary.md` compares the retained Villain
   connected-cluster estimate with the literal Wilson local expansion.
5. `wilson_all_volume_state.md` separates the proved all-volume state theorem
   from the still conditional massless-pole continuation.

Each record names one deterministic Python check, one stored JSON result and
one plain-text execution record. The programs verify finite arithmetic,
matrix identities or metadata consistency. They do not replace the analytic
proofs in the manuscript and do not certify an unrestricted continuum limit.
