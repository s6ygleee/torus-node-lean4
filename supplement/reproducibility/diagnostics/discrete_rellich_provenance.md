For unit-torus periodic coexact lattice forms with
\[
 \|u_L\|_{L^2}^2+\|d_au_L\|_{L^2}^2+\|\delta_au_L\|_{L^2}^2\leq C,
 \qquad a=L^{-1},
\]
the Fourier low-mode subspace is finite-dimensional and the high-mode tail
obeys
\[
 \sum_{|k|>K}|\widehat u_L(k)|^2\leq C(1+K^2)^{-1}.
\]
The low/high split and a diagonal argument yield an \(L^2\)-convergent
subsequence of the standard interpolants.  This is a conditional compactness
lemma for bounded deterministic periodic geometry.  It does not establish
tightness of the interacting torus measure or compactness for the raw Poisson
source.

This item is an analytic compactness argument rather than a numerical
calculation.  The accompanying public description is
